진단 작업 흐름

수신한 프레임에서 고장코드와 전기차 값을 읽고, 성공한 읽기 명령은 다음 스캔에 다시 씁니다. 새 테이블은 만들지 않습니다.

  1. 1. 블루투스 수신
    이 화면에서 진단기를 연결합니다. BLE는 Chrome·Edge, 클래식은 시리얼, 아이폰 웹은 블루투스 불가.
  2. 2. 고장코드·전기차 값
    스캔 결과가 코드와 배터리 값을 뽑습니다. 코드 이름은 지식 고장코드를 봅니다.
  3. 3. CAN 명령·해석
    읽기 명령은 진단 명령, 바이트 해석은 역분석에서 고친 뒤 다음 스캔에 적용됩니다.
  4. 4. 이더넷(DoIP)
    차량과 같은 망의 이 서버에서만 연결됩니다. 이더넷 진단은 실험 기능입니다.
  5. 5. 학습 저장
    성공한 읽기 명령만 차종·제조사 기록으로 남고, 다음 계획에 붙습니다. 지우기 명령은 학습하지 않습니다.
  6. 6. AI·다른 화면
    설명은 AI 연결이 켜져 있을 때 씁니다. 수집은 블루투스 수집, 저장된 스캔은 스캔 이력입니다.
